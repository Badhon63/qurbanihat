# QurbaniHat - Livestock Booking Platform

## Project Overview

QurbaniHat is a modern livestock marketplace where users can explore animals such as cows, goats, and buffalo for Qurbani. Users can view detailed information and place bookings after authentication.

https://your-live-link.vercel.app

---

## Features

- User authentication with Better Auth (Email & Google)
- Conditional navbar (login, logout, user info, avatar)
- Protected routes for animal details and profile pages
- Browse all animals with detailed information
- Sort animals by price
- Dynamic animal details page
- Booking form (login required)
- Toast notifications for booking, login, register, and update actions
- Profile page showing user name, email, and image
- Update profile feature (name and profile image)
- Responsive design for mobile, tablet, and desktop
- Loading states during data fetching
- Custom Not Found page
- Smooth UI animations using Animate.css
